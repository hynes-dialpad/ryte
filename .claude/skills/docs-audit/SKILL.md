# Ryte Documentation Audit

Audit documentation against current behavior without turning documentation cleanup into a broad rewrite.

## Workflow

1. Resolve the selected document, source area, or release workflow and distinguish maintained docs from generated output or private notes.
2. Verify commands, paths, package names, release steps, and security/privacy claims against current source and package scripts.
3. Classify a finding as broken instruction, stale behavior, missing contract, or optional improvement. Confirm each finding with current source before reporting it.
4. In report mode, return the handoff without edits. In apply mode, update one coherent documentation surface and run the narrowest command or link check that proves it.
5. Keep session notes and real user notes out of the audited corpus unless explicitly named by the user.

## Output

Report scope, verified findings, applied corrections when authorized, validation, and the next focused documentation action.
